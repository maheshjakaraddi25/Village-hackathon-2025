## ⚡ Quick Start

### 1. Clone / enter project
```bash
cd id-verify-ai
```

### 2. Backend setup
```bash
cd backend
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

# Set your Anthropic API key
export ANTHROPIC_API_KEY=sk-ant-...

# Start the API server
uvicorn main:app --reload --port 8000
```

### 3. Frontend setup (new terminal)
```bash
cd frontend
npm install
npm run dev
# → http://localhost:5173
```

### 4. Generate synthetic test IDs (optional)
```bash
cd backend
pip install faker pillow  # if not installed
python generate_test_ids.py
# → synthetic_data/ with 30 labeled images (6 fraud types × 5 each)
```

## 📡 API Reference

### `POST /verify`
Upload and analyze an ID document.

**Request:** `multipart/form-data`
| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id_doc` | File | ✅ | Primary ID image (JPEG/PNG/WebP, max 10MB) |
| `support_doc` | File | ❌ | Second document for Level 3 cross-matching |

**Response:** Full `VerificationResult` JSON — see below.

### `POST /synthetic-test`
Returns a pre-baked demo result without uploading anything. Great for hackathon demos.

### `GET /health`
```json
{ "status": "ok", "model": "claude-sonnet-4-20250514" }
```

## 🧪 Test Cases

Use the synthetic IDs in `synthetic_data/` to test each fraud type:

| File pattern | What it tests |
|---|---|
| `none_*.png` | Genuine ID — expect PASS |
| `expired_*.png` | Expired ID — expect LV4 REJECT (NIST IAL2) |
| `expiring_soon_*.png` | Expires in <30 days — expect LV4 WARN ⚠ |
| `wrong_format_*.png` | Bad date format — expect LV1 WARN |
| `font_mismatch_*.png` | Mixed fonts — expect LV1 flag |
| `glare_*.png` | Simulated glare — expect LV2 low OCR confidence |
